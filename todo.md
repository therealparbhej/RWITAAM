# Modern Cafe Website - MVP Development Plan

## Core Files to Create/Modify:
1. **index.html** - Main homepage with all sections (Hero, About, Services, Contact)
2. **style.css** - Complete styling with responsive design, animations, and color palette
3. **script.js** - Frontend JavaScript for interactions and form handling
4. **server.js** - Node.js Express server for backend routing and contact form
5. **package.json** - Update dependencies for Node.js backend
6. **public/** - Static assets directory structure

## Implementation Strategy:
- Single-page application with smooth scrolling sections
- Mobile-first responsive design
- Warm color palette: #1C1C1C, #F4B183, #FFF3E0
- Typography: Poppins for headings, Open Sans for body
- Express server for contact form handling
- Modern animations and hover effects

## Sections:
1. Hero - Coffee splash background, title, CTA buttons
2. About - Cafe story with decorative elements
3. Services - Grid layout with service cards
4. App Download - CTA section
5. Contact - Form with backend integration
6. Footer - Social links, contact info

## Dependencies:
- Express.js for server
- Nodemailer for contact form emails
- Body-parser for form data
